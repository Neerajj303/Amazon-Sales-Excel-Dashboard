# Amazon Sales Excel Dashboard

## 📊 Project Overview

An Excel-based Sales & Operations Analytics Dashboard designed to analyze e-commerce sales data and convert raw transactional data into meaningful business insights.

The project combines Excel formulas, XLOOKUP, PivotTables, Slicers, KPI analysis, and dashboard visualization to evaluate sales performance, revenue, products, regions, cancellations, customers, and delivery performance.

---

## 🎯 Project Objective

The main objective of this project is to analyze e-commerce business data and answer important business questions such as:

- What is the overall sales performance?
- Which products and categories generate the highest sales?
- Which regions perform best?
- Which regions have higher cancellation levels?
- What is the average delivery time?
- How many orders are delivered quickly?
- What is the effective sales/revenue performance?
- How do regional sales compare with their targets?
- How can customer and product master data be integrated with sales transactions?

## 📁 Workbook Structure

### Dashboard
Interactive dashboard presenting key business KPIs and visual analysis.

### KPI
Contains the major performance indicators used to summarize sales and operational performance.

### KPI Analysis
Detailed analysis supporting the dashboard KPIs, including product, regional, delivery, and cancellation analysis.

### Pivot & Slicer
Interactive PivotTable analysis using slicers for filtering and exploring business performance.

### AmazonSales
Main transactional dataset containing order, customer, product, sales, delivery, and regional information.

### ProductMaster
Product reference data used to retrieve product names, categories, and cost information.

### CustomerMaster
Customer reference data used to retrieve customer details and customer types.

### RegionGoals
Regional sales targets used for performance comparison.

### Brainstorming
Contains the initial business questions and analytical planning used to develop the project.

## 🧮 Excel Techniques Used

### XLOOKUP
Used to connect the main sales dataset with product and customer master tables.

### IF Functions
Used for classification and business logic such as order status and delivery performance.

### SUM / SUMIF / SUMIFS
Used for sales, revenue, regional, product, and category calculations.

### COUNTIF / COUNTA
Used for order and status-based calculations.

### AVERAGEIFS
Used for calculating average delivery performance.

### PivotTables
Used to summarize and analyze sales, orders, regions, products, and cancellation data.

### Slicers
Used to create interactive filtering for dashboard analysis.

### Date & Delivery Calculations
Used to calculate delivery duration and classify delivery performance.

## 💡 Business Analysis

The dashboard provides analysis across multiple areas:

### Product Analysis
